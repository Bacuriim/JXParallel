# Contributing to JXParallel

We welcome contributions from developers who care about JavaFX compatibility, low-overhead runtime design, and safe parallel execution.

## Workflow

1. Open or review an issue before large changes.
2. Keep changes focused and minimal.
3. Add or update tests for behavior changes.
4. Ensure the project remains buildable for the current supported Java baseline.
5. Document any behavioral difference from JavaFX.

## Coding expectations

- prefer compatibility over micro-optimization
- keep the API familiar to JavaFX developers
- document edge cases and unsupported behavior
- maintain thread safety and clear lifecycle ownership
